# Next Gen Data Workspace

NGDW 在 IML Wizard 中提供示波器、录波回放和后处理。离线安装程序和对应的 SHA-256 校验文件在 [GitHub Releases](https://github.com/Physis-Global-Research-Center/NGDW-PUBULISH-PAGE/releases) 下载。

首版面向 64 位 Windows 上的 IML Wizard 1.0.1（32 位）。开始安装前请关闭 IML Wizard，运行安装程序并确认 IML 的安装目录。安装完成后重新打开 IML Wizard，在工具栏点击 NGDW 波形图标。

使用 JTAG 实时采集前，在本机配置兼容的 CCS 调试会话和固件。需要搜索 ELF/DWARF 变量时，在 NGDW 的变量搜索窗口选择匹配的 `.out`。
